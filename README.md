# YC HEDGE FUND

Official website for YC Hedge Fund, an independent quantitative research entity focused on AI-driven financial analysis and investing.

## Overview

This repository hosts the static website for YC Hedge Fund, built using HTML, Tailwind CSS, and vanilla JavaScript. It is deployed automatically using [GitHub Pages](https://pages.github.com/).

The site features:
- Our mission and investment philosophy.
- Links to our core AI-powered research tools hosted on Hugging Face.
- A live-updating section for AI-generated market signals, sourced from an external `signals.csv` file.
- A research soundtrack powered by Spotify.
- Responsive design for various devices.

## Live Site

The website is live at: [https://lacomaofficial.github.io](https://lacomaofficial.github.io)
